## Supporting evidence

If you have created any other code, documents, planning materials, or assets related to this project, add them to a new directory called `cafe-sales-data/supporting-evidence/`.

This folder is for any extra work that shows your thinking, development, and solution design for the café project. It can include completed work, partial work, drafts, prototypes, testing files, planning documents, diagrams, screenshots, spreadsheets, or media assets.

### Folder structure

- Place all supporting files inside `cafe-sales-data/supporting-evidence/`.
- If you have more than one distinct solution or project, create a separate folder for each one.
- For example:

```text
cafe-sales-data/
└── supporting-evidence/
    ├── point-of-sale/
    ├── stock-database/
    └── planning-documents/
```

### What to include

You may include:

- Previous coding work related to the café scenario.
- Design drafts or prototype solutions.
- Planning documents completed earlier in class.
- Screenshots, mock-ups, diagrams, or flowcharts.
- Data files, spreadsheets, or database files.
- Incomplete or in-progress work that shows your development process.

### Requirements

For each distinct code or project folder:

- Include clear comments in any code files.
- Add a `README.md` file that explains:
  - what the files are
  - the purpose of the solution
  - how the program or system works
  - the main program logic or structure
  - what is completed and what is still being developed

### Why this matters

This section allows you to upload previous or additional work connected to programming and designing digital solutions for the café. It also helps show your design thinking, development process, and evidence of progress over time.
